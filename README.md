# Edge Expert

Edge Expert is a comprehensive real estate platform built with React, Vite, and Tailwind CSS. It features custom dashboards for customers, brokers, and developers, alongside property discovery, housekeeping, interior design, and membership package features.

## 🚀 Features

- **Property Listings & Discovery**: Buy, Rent, PG/Co-Living, Commercial, and New Projects.
- **Role-based Dashboards**:
  - Customer Panel
  - Broker Panel
  - Developer Panel
  - Admin Panel
- **Additional Services**:
  - Housekeeping, Packers & Movers, Painting, Renovation
  - Interior & Architectural Design
  - Subscription & Membership Packages

## 🛠️ Tech Stack

- **Frontend**: React.js, Vite, Tailwind CSS, Lucide Icons, Framer Motion
- **Routing**: React Router DOM

## 📦 Getting Started

### Installation

```bash
# Navigate to the client directory
cd client/client

# Install dependencies
npm install

# Start the development server
npm run dev
```

### Production Build

```bash
cd client/client
npm run build
```
