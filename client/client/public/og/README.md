# Thumbnail Images for Component Sharing

This folder contains thumbnail images used when sharing individual components on social media platforms.

## Required Thumbnails

Each component should have its own thumbnail image (1200x630 pixels) for optimal social media sharing:

- `thumbnail.png` - Home Page
- `about-thumbnail.png` - About Us Page  
- `contact-thumbnail.png` - Contact Us Page
- `properties-thumbnail.png` - Properties Page
- `services-thumbnail.png` - Services Page
- `blog-thumbnail.png` - Blog Page
- `developer-thumbnail.png` - Developer Package
- `broker-thumbnail.png` - Broker Package
- `owner-thumbnail.png` - Owner Package
- `housekeeping-thumbnail.png` - Housekeeping Services
- `interior-thumbnail.png` - Interior Design
- `featured-thumbnail.png` - Featured Properties
- `luxury-thumbnail.png` - Luxury Properties
- `affordable-thumbnail.png` - Affordable Housing
- `commercial-thumbnail.png` - Commercial Properties
- `projects-thumbnail.png` - New Projects

## Image Specifications

- **Size**: 1200x630 pixels (Facebook/LinkedIn optimal)
- **Format**: PNG or JPG
- **Content**: Should represent the specific component/page
- **Text**: Include component name and Edge Expert branding
- **Quality**: High resolution for crisp display across platforms

## Usage

These images are automatically used when:
- Sharing component links on social media
- WhatsApp link previews
- Search engine rich snippets
- Open Graph meta tags
